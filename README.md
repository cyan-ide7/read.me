## 🌐 Personal Portfolio Website

A performant personal portfolio website built with **Next.js**, **Tailwind CSS v4**, and **Framer Motion**.

### Getting Started Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build & Static Export
```bash
npm run build
```
Generates static production output in the `out/` folder for deployment.
